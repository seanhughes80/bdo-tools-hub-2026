## What BDO Tools Hub Does

BDO Tools Hub provides a browser workspace for preparing, recording, and reviewing activities in Black Desert Online. Bartering calculations, hunting estimates, contribution point planning, and recurring activity tracking are available together instead of being separated across different tools.

Record hunting sessions, follow progress, save notes, and check accumulated silver totals while managing your regular game plans. The dashboard keeps the related calculations, reminders, and activity records in one location.

## Included Tools

- Work out bartering costs and maintain associated progress records.

- Calculate contribution point needs with OCR-assisted data entry.

- Save personal notes alongside reminders.
